# docs

The documents. `decisions/` holds one file per decision that shapes the
architecture, each stating what was chosen, the reason, what was given up, and
what would change it. The rest holds the notes a reader needs to weigh a
published number: what the suite measures, what it does not, and where it
disagrees with the prior work.

A number in here carries the command that produced it, and a rule stated in here
that no check refuses says so at the rule.
