# results

Result records, as data, one per run. A record answers which case at which
version, which engine at which version, which configuration in full, which
reference with which bound, what the machine was, what the suite's own commit
was, the metric value with its uncertainty, and how long it took. Which fields
are required and what refuses a record missing one is issue #10 and issue #40.

Nothing here is edited after it is written. A record that was corrected is a
record that no longer describes the run it names.
